# 班級管理與隨機點名系統

純前端網頁應用（HTML + CSS + JavaScript），不需要安裝任何套件、也不需要後端伺服器。

## 功能

| 選單 | 說明 |
| --- | --- |
| 班級管理 | 新增、編輯、刪除班級；顯示班級列表與人數；可一鍵跳到該班的學生管理 |
| 學生管理 | 選擇班級後，新增、編輯、刪除該班學生 |
| 隨機點名 | 選擇班級，按「點名」後隨機顯示一位學生的名字；可選擇是否「不重複點名」 |

規則：

- 班級名稱不可重複；同一班級內學生姓名不可重複。
- 刪除班級或學生前會先確認。
- 沒有學生的班級無法點名。

## 檔案結構

```
Test_2/
├── index.html   頁面結構（左側選單、右側內容、版權資訊）
├── styles.css   樣式（含手機版的響應式版面）
├── script.js    功能邏輯（班級/學生管理、隨機點名、資料儲存）
└── README.md    說明文件
```

## 在其他電腦上使用

1. 將整個資料夾（`index.html`、`styles.css`、`script.js`、`README.md`）複製到另一台電腦，例如用隨身碟、雲端硬碟或壓縮檔。
2. 確認三個檔案放在**同一個資料夾**內。
3. 雙擊 `index.html`，用瀏覽器開啟即可。

建議使用較新的瀏覽器（Chrome、Edge、Firefox、Safari 皆可）。

### 以本機伺服器開啟（選用）

通常直接開啟檔案即可。若想用網址方式開啟，可在資料夾內執行下列任一指令，再於瀏覽器開啟 `http://localhost:8000`：

```bash
python -m http.server 8000
```

```bash
npx serve .
```

### 發佈到網路（選用）

由於只有靜態檔案，可直接放到 GitHub Pages、Netlify、Cloudflare Pages 等靜態網站服務，之後任何電腦用網址即可開啟。

## 資料儲存說明

- 資料儲存在瀏覽器的 `localStorage`（鍵名 `class-roll-call-v1`），重新整理或關閉頁面後仍會保留。
- **資料只存在目前這台電腦的這個瀏覽器中。** 把資料夾複製到別台電腦，開啟的是空白的系統，需要重新輸入班級與學生。
- 清除瀏覽器資料、使用無痕模式，或更換瀏覽器，都會看不到原本的資料。
- 若需要跨電腦共用同一份名單，需另外加入匯出／匯入功能或後端資料庫。
